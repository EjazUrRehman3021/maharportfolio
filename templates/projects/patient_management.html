Patient Management System

This is a learning-based web project developed to understand full-stack development using modern technologies.

🛠 Technologies Used

  • Backend: FastAPI (Python)
  • Frontend: React.js
  • Database: SQLite
  • Purpose: Learning & Practice Project

✨ Key Features

  • Patient registration and record management
  • Secure login system
  • Add specialist doctors
  • Doctor availability management
  • Appointment scheduling with time slots

⚙ Project Requirements

To develop a project like this Patient Management System, the following software and tools are required:

💻 Software Requirements

  • Python (Version 3.9 or above)
  • VS Code (or any code editor)
  • Node.js & npm (for React frontend)
  • Web Browser (Chrome / Edge)

📦 Backend Libraries (Python)

  • FastAPI
  • Uvicorn (ASGI server)
  • SQLite (built-in with Python)
  • Pydantic (for data validation)

🎨 Frontend Libraries (React)

  • React.js
  • Axios (API communication)
  • React Router (navigation)

🗄 Database

SQLite database was used in this project. It is a lightweight, file-based database and is best suited for small-scale and learning-based applications.
