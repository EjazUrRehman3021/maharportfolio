FIR Filter Design

This is a comprehensive, pure AI-based Digital Signal Processing (DSP) project focusing on the design and optimization of Finite Impulse Response (FIR) filters. The system tests filtering performance using various windowing techniques on real-time signals, with all AI-generated results strictly verified on actual hardware.

🛠 Technologies & Components Used

  • Microcontroller: ESP32
  • Hardware Kits: Dedicated DSP Kits
  • Testing Equipment: Function Generator & Oscilloscope
  • Filter Type: FIR (Finite Impulse Response)

✨ Key Features

  • Implementation of 11 distinct windowing techniques
  • Processing of real-time signals including Audio, ECG, EEG, and Vibration
  • Dual operational modes for exploratory and constraint-based testing
  • Pure AI-based filter design with results rigorously verified on physical hardware using function generators and oscilloscopes

⚙ Project Requirements

To successfully implement and test this FIR Filter Design project, the following parameters, hardware, and signals are utilized:

💻 Real-Time Signals

  • Audio Signals
  • ECG (Electrocardiogram)
  • EEG (Electroencephalogram)
  • Vibration Monitoring Signals

🪟 FIR Windowing Techniques (11 Types)

To design the FIR filters and optimize their characteristics, the following window functions were tested:

  • Rectangular
  • Hann
  • Triangular
  • Blackman
  • Tukey (alpha=0.5)
  • Bartlett
  • Hamming
  • Bohman
  • Flattop
  • Blackman-Harris
  • Parzen

⚙ Operational Modes

The system was tested using two distinct operational modes:

  • 1. Exploratory Mode: Individual real-time signals (Audio, EEG, ECG, and Vibration) are processed one by one to observe the isolated effects of different window-based FIR filters.
  • 2. Constraints Mode: Testing the filters under specific system constraints and real-time operational limits to evaluate their hardware boundaries and optimal performance metrics on the ESP32.
